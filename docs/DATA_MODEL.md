# Data model

Mirror of `src/db/schema/*`. Drizzle uses `casing: 'snake_case'`, so camelCase fields map to snake_case columns. Root tables carry `household_id`; children are scoped through their parent.

## M0 (live)

| Table | Purpose | Notes |
|---|---|---|
| `user`, `session`, `account`, `verification` | better-auth identity | generated by `pnpm dlx auth@1.7.13 generate`; never add app columns |
| `household` | planning unit and settings | `timezone` (Europe/London), `week_starts_on` (0 = Monday), `weeknight_prep_cap_min`, `include_optional_ingredients`, `prep_factor`, `capture_token` |
| `person` | an eater; the domain identity | `user_id` unique nullable (virtual person when null), `role` manager/member, `kind` adult/child/guest, `is_default_eater`, `diet_rules[]`, body/target columns used from M3, `gym_weekdays[]`, `snack_pct`, `show_energy`, `archived_at` |
| `household_token` | single-use invite / password reset links | `kind` invite/reset, `expires_at`, `used_at` |

Migrations: `0000_extensions.sql` (pg_trgm), `0001_init.sql`.
